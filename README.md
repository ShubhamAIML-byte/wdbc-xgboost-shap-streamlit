
# WDBC AI Diagnostic

Explainable breast cancer classification using:

- XGBoost
- Wisconsin Diagnostic Breast Cancer Dataset
- Stratified 5-Fold Cross-Validation
- 95% Confidence Intervals
- SHAP Explainability
- Streamlit

## Files

- `app.py` - Streamlit application
- `model.joblib` - trained XGBoost pipeline
- `metrics.json` - cross-validation metrics and confidence intervals
- `feature_names.json` - WDBC feature names
- `requirements.txt` - deployment dependencies

## Deployment

Upload all files to a GitHub repository and deploy the repository
using Streamlit Community Cloud.

## Disclaimer

This application is for research/educational purposes and is not
a medical diagnostic device.
